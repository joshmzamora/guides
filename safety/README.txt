MBPP Safety Guide

TO OPEN

1. Make sure the downloaded ZIP file has been fully extracted.
2. Open the safety folder.
3. Double-click index.html.
4. Use the controls on the page to move through the presentation.

ABOUT THIS GUIDE

This guide brings the safety presentation and its supporting material together
in one place. Keep the complete safety folder together so all files continue to
load correctly.

Chrome or Edge is recommended. No installation or server is needed.
