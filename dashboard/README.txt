MBPP Technician Dashboard

TO OPEN

1. Make sure the downloaded ZIP file has been fully extracted.
2. Open the dashboard folder.
3. Double-click mbpp_technician_dashboard.html.

ABOUT THIS DASHBOARD

The dashboard keeps common lab resources together in one self-contained HTML
file. Edits are saved only in the browser on the computer being used.

Use the dashboard's editing and download controls to create an updated portable
copy. Open the newly downloaded HTML file to use the updates embedded in that
copy. Chrome or Edge is recommended, and no installation or server is needed.
