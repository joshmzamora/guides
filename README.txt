MBPP Guides

This repository contains three independent browser-based guides:

- safety
- intern
- tech

No coding, installation, or server setup is required.
Each folder also has its own README.txt with more information.


HOW TO DOWNLOAD AND OPEN THE GUIDES

1. On GitHub, select Code, then Download ZIP.
2. Find the downloaded ZIP file and select Extract All.
3. Open the extracted guides-main folder.
4. Open the folder for the guide you want to use.
5. Double-click that guide's start file.

Do not open the guides while they are still inside the ZIP file.


SAFETY

Folder:
safety

Start file:
safety/index.html

How it works:
This is the safety presentation. Open index.html and use the controls shown
on the page to move through the presentation. Keep the complete safety folder
together so its supporting files remain available.


INTERN

Folder:
intern

Start file:
intern/index.html

How it works:
This is the MBPP lab onboarding guide. Open index.html and use the page
controls to move through its sections and slides. The page uses app.js,
styles.css, and the assets folder, so keep all intern files together.

The local version may hide the intro video when opened directly from a
computer. The guide content, slides, and resources should still work.


TECH

Folder:
tech

Start file:
tech/mbpp_technician_dashboard.html

How it works:
This is the technician dashboard. It is contained in one HTML file, so open
mbpp_technician_dashboard.html directly in a browser.

Edits are saved only in that browser on that computer. Use the dashboard's
editing and download controls when you need to create an updated portable HTML
copy. Open the newly downloaded file to use the updates embedded in that copy.


IMPORTANT

- Keep each guide's files inside its original folder.
- Do not rename or move the assets folders.
- Chrome or Edge is recommended.
- If a guide does not respond, confirm that the ZIP was fully extracted,
  reopen the correct start file, and refresh the browser.
